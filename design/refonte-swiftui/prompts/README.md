# Utiliser les prompts

Commencer par 00-MASTER, puis 01-AUDIT. Les lots 02–03 fondent les primitives ; 04–10 couvrent les surfaces ; 11–14 couvrent assets, motion, recette et revue. Passer ensuite le brief de la vue correspondante généré dans `dist/prompts/<id>.md` par `npm run build`.

Chaque brief référence le vrai fichier ou conteneur repéré et la base Git. L’agent d’intégration doit relire sa version actuelle, ne pas copier le studio comme application, et compléter la matrice de parité. Les 57 briefs de vue ne prouvent pas un inventaire exhaustif des sous-formulaires.
