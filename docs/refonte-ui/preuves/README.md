# Journaux de recette

Sorties des commandes locales exécutées, sans base ni compte de production.
Les fins de ligne et espaces terminaux ont été normalisés pour le diff Git ;
aucun verdict, erreur ou résultat de test n’a été retiré. Les copies terminales
brutes restent dans `_handoff/preuves-brutes/` (dossier local non versionné).

Les tentatives initiales échouées sont conservées pour distinguer les défauts
constatés, prérequis et corrections des preuves finales. Les fichiers `final`
et les résultats structurés référencés par `../REPRISE.md` donnent les verdicts
retenus. Une commande réussie ne prouve que le périmètre qu’elle exécute.
